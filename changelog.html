更新日志

每个版本改了什么

按时间倒序，包含 V4、V4.1、V4.2、V4.3 的全部更新记录。 更细的根因与验证记录在 GitHub 仓库的 docs/V4.x/ 下。

  • v4.3 · 0.1.3 最新 2026-11-08
    • 每个模块都有独立工作台：安装后在侧栏点击模块，或从模块中心点「打开」，即可进入 /modules/:id。工作台集中展示状态、版本、作者、许可证、资源限制、声明式页面、仪表盘卡片、工具试运行、模型卡、记录类型、权限与最近审计。
    • 没有声明页面的模块也能用：Cardia、relay 等分析模型，以及数据导入/工具类模块，都有工作台；没有 ui.pages 时显示状态、模型卡、工具、权限和审计，不再只能停留在模块列表。
    • 侧栏直达模块：侧栏直接列出已安装模块，点击进入工作台；模块中心每个模块增加「打开」按钮，模块详情面板增加「打开工作台」。
    • 助手「+」选择模块：对话输入区新增「+」，可勾选本轮优先使用的模块。所选模块以 chips 显示，随消息发送 moduleIds；切换会话会恢复上次选择，用户消息和透明面板都会回显本轮模块。
    • Agent 优先所选模块：所选模块的工具排在工具目录前面，并在系统提示词中列出模块名称、工具与页面；其他已安装且启用的模块工具仍然可用，不是白名单。
    • 模块编码与安装校验：新增 Node 校验脚本，检查 module.json 的 BOM / 乱码 / 结构，以及 .ehmod 的 ZIP 内容与 SHA-256；发布前可运行 npm run check:modules 与 npm run check:packages。
    • 声明式页面返回工作台：从模块页面点「返回模块」现在回到该模块工作台，而不是模块列表。
  • v4.2 · 0.1.2 已发布 2026-11-07
    • 其他分析引擎可以正常分析心电图：修复 relay-ecg 等非 Cardia 引擎的输入维度不匹配与「cannot reshape」错误，7 个逐搏分类模型均可完成分析。
    • 单导联自动适配：手环/手表的单导联 ECG 会自动复制为模型要求的双导联，并重采样到 360 Hz。
    • 错误信息可读：心搏不足、R 峰检测失败等改为中文提示，不再直接暴露 Python 异常。
    • 睡眠模型不再误选：relay-sleep 的睡眠分期模型不再出现在心电记录的可选分析引擎中。
    • 补全心率与质量指标：relay 分析现在同时给出平均/最小/最大心率、SDNN、RMSSD、pNN50、N/SVEB/VEB/F 比例与信号质量分。
    • 手表结果提示：单导联/非 MLII/非 360 Hz 记录会显示「手表/可穿戴结果仅供参考」，说明 SVEB 等比例可能偏高。
  • v4.1 · 0.1.1 已发布 2026-11-06
    • 助手回复按 Markdown 显示：标题、加粗、列表、表格、代码块、链接不再以原始符号出现；流式输出保留末尾光标，站内链接可直接跳转，外链新窗口打开。
    • 助手不再过度免责：回复优先给结论和可执行建议，不再每轮追加「以上为数据解读，不构成医学诊断」；免责声明由界面统一展示一次。仅在涉及诊断、用药、剂量或急症症状时提示就医。
    • 缺少数据时也能给建议：说明缺哪项数据、如何补齐，并在现有信息范围内给出判断，不再用「我不知道 / 无法判断」代替回答。教练模式同样优先给出 1–3 个可执行步骤。
  • v4 · 0.1.0 已发布 2026-11-06
    • 模块安装不再依赖用户机网络：安装包内置官方模块依赖的离线 wheel 仓库，安装功能型模块时优先离线安装，失败才联网兜底。
    • 依赖安装错误可诊断：失败时返回实际模式、缺失包名，并新增 offline-wheel-missing 原因。
    • 核心 Python 升级后自动重建模块环境：不再复用旧版本 venv / deps。
    • 依赖瘦身：relay-ecg / relay-sleep 不再重复安装核心已内置的 numpy / onnxruntime / wfdb。
  • v0.1.0-alpha 已发布 2026-11-02
    • 首个公开版：ECG 与 Apple / 小米 / Samsung 健康数据导入，Cardia 2.0 分析、记录、趋势与报告。
    • 模块生态：模块市场与 30+ 可选模块，权限、审计与 SHA-256 校验。
    • AI 助手：可选多厂商模型与本地 Ollama，Key 用 DPAPI 加密，只发送摘要与测量。
    • 稳定性：修复长记录逐搏分析卡死（O(n²) → O(n log n)），新增取消、重试、暂停与卡死看护。
