Changelog

What changed in each version

Newest first, covering all V4, V4.1, V4.2 and V4.3 updates. Root-cause notes and verification records live under docs/V4.x/ in the GitHub repository.

  • v4.3 · 0.1.3 Latest 2026-11-08
    • Every module gets its own workbench: after install, open a module from the sidebar or the module center's “Open” button to reach /modules/:id. The workbench shows status, version, author, license, resource limits, declarative pages, dashboard cards, tool runner, model card, record types, permissions and recent audit.
    • Modules without declared pages are usable too: Cardia, relay and import/tool modules get the same workbench; without ui.pages it shows status, model card, tools, permissions and audit instead of stopping at the module list.
    • Sidebar module shortcuts: installed modules are listed directly in the sidebar; the module center adds an “Open” button and the module detail sheet adds “Open workbench”.
    • Assistant “+” module picker: choose priority modules for the turn. Selected modules appear as chips and are sent as moduleIds; switching conversations restores the last selection, and user messages plus the transparency panel show the modules used for the turn.
    • Agent prioritizes selected modules: their tools are sorted first and listed in the system prompt with names, tools and pages; other installed and enabled module tools remain available — it is a priority, not a whitelist.
    • Module encoding and package checks: new Node scripts validate module.json BOM / mojibake / structure and .ehmod ZIP contents plus SHA-256; run npm run check:modules and npm run check:packages before release.
    • Declarative pages return to the workbench: “Back to modules” on a module page now returns to that module's workbench, not the module list.
  • v4.2 · 0.1.2 Released 2026-11-07
    • Other analysis engines now work on ECG: fixed input-shape mismatches and “cannot reshape” errors in relay-ecg and other non-Cardia engines; all seven beat-classification models complete.
    • Single-lead adaptation: single-lead watch ECGs are duplicated to the model's two leads and resampled to 360 Hz automatically.
    • Readable errors: insufficient beats and R-peak detection failures now show actionable messages instead of raw Python exceptions.
    • No more sleep models in ECG analysis: relay-sleep sleep-staging models are no longer offered as ECG analysis engines.
    • Heart-rate and quality metrics: relay analyses now also report mean/min/max heart rate, SDNN, RMSSD, pNN50, N/SVEB/VEB/F ratios and a signal-quality score.
    • Wearable result notice: single-lead / non-MLII / non-360 Hz records show a “wearable results are for reference only” notice, explaining that SVEB ratios may be inflated.
  • v4.1 · 0.1.1 Released 2026-11-06
    • Markdown replies: headings, bold text, lists, tables, code blocks and links render properly instead of showing raw symbols; streaming keeps the trailing cursor, in-app links navigate and external links open in a new window.
    • Less defensive answers: replies lead with conclusions and actionable advice; the fixed per-answer disclaimer is gone and shown once by the UI. A seek-care recommendation appears only for diagnosis, medication, dosage or acute symptoms.
    • Advice despite missing data: the assistant says which data is missing and how to fill it in, instead of answering “I don't know / cannot judge”; coach mode also leads with 1–3 actionable steps.
  • v4 · 0.1.0 Released 2026-11-06
    • Module install no longer depends on the user's network: the installer bundles an offline wheelhouse for official module dependencies; functional modules install offline first and only fall back to the network on failure.
    • Diagnosable dependency errors: failures return the actual mode and missing package names, plus a new offline-wheel-missing reason.
    • Module environments rebuild after a Python upgrade: old venvs and dependencies are no longer reused.
    • Leaner dependencies: relay-ecg / relay-sleep no longer reinstall numpy / onnxruntime / wfdb that the core already bundles.
  • v0.1.0-alpha Released 2026-11-02
    • First public release: ECG and Apple / Xiaomi / Samsung health-data import, Cardia 2.0 analysis, records, trends and reports.
    • Module ecosystem: a module marketplace with 30+ optional modules, permissions, audit log and SHA-256 verification.
    • AI assistant: optional multi-vendor models and local Ollama, with DPAPI-encrypted keys and summaries only.
    • Stability: fixed long-record beat-analysis stalls (O(n²) → O(n log n)), plus cancel, retry, pause and stall watchdog.

All module output and assistant answers are not medical advice; this is not a medical device and is not intended for diagnosis, treatment or replacing professional medical judgement.
