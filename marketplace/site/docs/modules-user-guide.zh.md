# eclipse health 模块使用指南

> 面向使用 eclipse health 的人。读完你会知道：模块能做什么、从哪里安装、权限怎么看，以及怎样让自己的 AI Agent 帮你做一个模块。
> 文档版本：2026-11-01 · 适用于 0.1.x。

## 1. 模块是什么

eclipse health 的核心只保留数据、权限、生命周期与审计。其余能力都以模块提供：

- 设备与数据源：Apple 健康、Garmin、Fitbit、Withings、GPX 轨迹、蓝牙设备等；
- 分析模型：HRV、ECG 心搏分类、睡眠分期等；
- 界面组件：仪表盘卡片、图表、活动热力图；
- 导出器：WFDB、EDF/BDF 等；
- AI 工具：提供给内置助手调用的受限工具。

官方模块和第三方模块使用同一套契约：独立 Python 进程、stdio JSON-RPC、逐项权限声明。模块可以卸载、替换，已安装数据由你决定保留还是删除。

## 2. 两个索引，三种来源

| 来源 | 收录什么 | 是否人工审核 |
|---|---|---|
| 官方索引 | 第一方模块，以及通过验证的第三方适配模块；第一方模块排在最前 | 第一方由项目维护；第三方只做自动扫描与验证 |
| 社区索引 | 社区提交的模块，允许专有/付费并显著标注 | 未人工审核，只有自动扫描 |
| 本地 `.ehmod` | 你从别处拿到的模块包，离线安装 | 无，安装前请自行确认来源 |

在应用的市场页里，官方和社区是两个标签页，条数与网站一致。社区模块始终显示「未审核」。扫描结果分绿、黄、橙、红：红色拒绝安装，黄/橙允许安装但会标注风险。

## 3. 如何安装

### 从应用内市场安装

1. 打开「模块」→「市场」；
2. 选择「官方索引」或「社区索引」，搜索或按分类筛选；
3. 点开模块详情，确认功能、输入输出、适用场景与限制；
4. 查看权限、依赖、许可证与 SHA-256；
5. 点安装，在权限确认页逐项同意。

首次安装有依赖的模块会为它创建独立 venv 并联网下载 Python 依赖，可能需要几十秒。

### 从本地 `.ehmod` 安装

1. 拿到 `.ehmod` 文件（ZIP 包）；
2. 打开「模块」→「从本地文件安装」；
3. 选择文件，核对 manifest 中的 ID、版本、权限与许可证；
4. 确认安装。

安装器会检查路径穿越、符号链接、压缩体积与 `checksums.json`。校验失败会中止安装。

## 4. 权限怎么看

权限只在安装或升级时授予。升级新增权限必须重新确认，不会自动继承。

| 权限 | 风险 | 含义 |
|---|---|---|
| `records:read` | 低 | 读取记录、测量与分析结果 |
| `records:write` | 中 | 创建或更新记录 |
| `records:delete` | 高 | 删除记录，默认不授予 |
| `files:user-selected` | 低 | 读取你主动选择的文件 |
| `files:export` | 中 | 写入你确认的导出目录 |
| `network` | 高 | 访问 `allowedHosts` 中列出的具体主机 |
| `llm` | 中 | 调用你配置的 LLM |
| `models:download` | 中 | 下载模型权重 |
| `ui:custom` | 高 | 在沙箱中提供自定义界面 |
| `system:notify` | 低 | 发送系统通知 |
| `system:background` | 中 | 最小化后继续在后台运行 |

判断原则：

- 只需要看数据却申请 `records:delete`，拒绝或换一个模块；
- 只处理本地文件却申请 `network`，先看它要访问哪些主机；
- `ui:custom` 意味着模块自带界面，风险更高，只给可信来源。

## 5. 数据与隐私

- 健康数据默认不出本机；应用不发遥测，不上报已安装模块列表；
- 模块日志不得包含波形、备注或原始文件名；
- 导出与报告由你主动触发；
- 卸载模块时可以选择保留或删除它的数据；
- 所有分析结果均为非医疗器械输出，不用于诊断或治疗。

## 6. 没有你想要的模块？

网站模块市场底部有「没有你想要的模块？」表单。填写模块名称、用途、输入、输出与需要的数据/权限，它会生成一段提示词：

1. 复制提示词，粘贴给你自己的 AI Agent（Claude Code、Cursor、Codex 等）；
2. Agent 会按 eclipse health 模块契约生成 `module.json`、worker 代码、测试与打包脚本；
3. 按它在仓库根目录打出的 `.ehmod` 包，在应用里用「从本地文件安装」装上好即可。

更完整的开发说明在 [Agent 版模块设计文档](modules-agent-guide.zh.md) 中，可以直接交给 Agent 阅读。

## 7. 常见问题

**模块安装失败？**
先看错误码：依赖安装失败通常是网络或版本冲突；`MODULE_CRASH` 表示模块启动即退出，可查看模块日志。

**模块更新后多了权限？**
必须重新确认。不同意可以留在旧版本或卸载。

**社区模块安全吗？**
社区索引只有自动扫描，没有人工审核。安装前看作者、仓库、权限与扫描结果，必要时先读源码。

**可以同时装两个同类引擎吗？**
可以。分析模型类模块通常允许切换或并排比较；数据写入仍由核心校验归属。

**模块能读我的全部记录吗？**
只有获得 `records:read` 才可读取；模块只能读写自己创建的记录，或自己声明 `recordTypes` 的记录。
