一次导入，从波形看到报告

从 ECG 和健康数据导入，到分析、记录、趋势与报告，全部在本机完成。

心电导入

支持 WFDB、CSV、EDF、SCP-ECG，以及 Apple 健康、Samsung、华为手表导出的 ECG（厂商格式标为实验性）。拖拽导入，导入前可预览与校正参数。

心搏分析

内置 Cardia 2.0 引擎输出信号质量、R 峰、逐搏 N / SVEB / VEB / F 分类与心率、间期测量；可切换引擎重新分析。

记录与趋势

记录库按时间、设备与标签筛选，波形可缩放平移；趋势页看指标变化，两条记录可以并排对比。

报告与分享

生成 PDF / PNG 报告，支持脱敏与「非诊断」水印，报告保存在本机，也可以导出分享。

AI 助手（可选）

可接 OpenAI、Anthropic 或本地 Ollama；API Key 存在 Windows 凭据管理器，只发送摘要与测量，工具调用过程可见。

本地与开放

数据存本机 SQLite，不做遥测；提供本机 REST、OpenAI 兼容端点与 MCP，供其他应用和 AI 调用。

自研分析模块

官方模块与第三方使用同一套契约。这里先讲清楚它们各自能做什么，再谈模型。

Cardia 2.0 · 内置心搏分类

随应用预装

打开应用就能用的 ECG 分析引擎。

把单导联 ECG 分成 N / SVEB / VEB / F 四类心搏，同时给出信号质量、心率与间期测量。无需安装模块，随核心一起提供。

  • 逐搏心律失常分类
  • 信号质量与心率 / 间期测量
  • 可在应用内切换引擎重新分析
直接下载应用 →

ECG 心搏分析

官方自研 · 可选模块

把一段心电切成心搏，标出正常搏动与早搏。

内置 7 个分类模型，可对同一段记录切换或并排比较；输出逐搏标签、各类占比与心率概览，适合科研复现和算法对照。

  • 逐搏 N / SVEB / VEB / F 标签
  • 7 个模型切换对照
  • WFDB、float32 与内联采样点输入
查看模块详情 →

睡眠分期分析

官方自研 · 可选模块

把整夜睡眠分到五个阶段，看清睡眠结构。

逐窗判断 W / N1 / N2 / N3 / REM，汇总各阶段时长与占比、夜间觉醒与睡眠效率；支持特征或原始 30 秒窗口，5 个模型可对照。

  • 五类睡眠分期
  • 睡眠结构摘要
  • 5 个分期模型对照

模块不是插件彩蛋，而是第一公民

核心保持最小：数据、权限、生命周期与审计。其余能力都可以替换。

独立进程

模块通过 stdio JSON-RPC 与核心通信，不 import 核心代码；崩溃隔离，可随时停用。

权限最小化

读记录、写记录、网络、后台运行等权限逐项授权；升级新增权限必须重新确认。

声明式 UI

组件与页面只使用受控组件和设计令牌；任意 React/CSS 仅限沙箱与主题作用域。

可卸载、可替换

官方功能也以模块交付，预装但可卸载；用户可锁定版本、切换 stable/beta 通道。

安全边界写在明面上

发布时执行结构、完整性、依赖、静态代码、密钥、权限 diff、网络白名单与模型格式扫描； 红色拒绝安装，黄色/橙色允许安装但显著标注。客户端不发送遥测，不上报已安装模块列表，健康数据默认不出本机。 所有分析结果均为非医疗器械输出，不用于诊断或治疗。
