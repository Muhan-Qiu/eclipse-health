# 健康评分规则（G2 · v1）

> 状态：规则评分，非诊断。所有区间来自公开健康建议，不是临床标准。
> 统一免责声明：**「基于公开区间规则的参考评分，不是医学诊断」**。

## 数据窗口与缺失

- 总窗口：最近 **30 天**；睡眠与步数使用最近 **7 天**。
- 无数据的分类**不返回**在 `categories` 中，也不参与总分；分类名进入报告级 `missing`。
- 分类内部分子项缺失时，只在 `missing` 里说明；分数由**可用子项按权重重新归一化**。
- 全部无数据：`overall=null`、`grade=unknown`、`categories=[]`、`missing` 列出全部五项。
- 成员不存在或数据库为空按空数据返回（HTTP 200），不抛 500。

## 分级

| 分数 | grade |
|---|---|
| ≥85 | excellent |
| ≥70 | good |
| ≥55 | fair |
| <55 | attention |
| 无数据 | unknown |

总分 = 各可用分类分数的算术平均（四舍五入）；缺项不拉低总分。

## 心脏 heart

子项与权重（仅对可用子项归一化）：

| 子项 | 权重 | 取值 | 评分 |
|---|---|---|---|
| 静息心率 | 0.40 | 健康数据 `heart-rate`：有 resting 标记取均值，否则取近 30 天 10% 分位；无健康数据时用最近 ECG 分析的 `heart_rate_mean` | 50–70:100；45–49 或 71–80:85；40–44 或 81–90:70；35–39 或 91–100:55；其余 40 |
| HRV | 0.25 | 最近 completed ECG 分析的 `rmssd` | ≥50:100；40–49:85；30–39:70；20–29:55；<20:40 |
| 异常搏动 | 0.20 | `svb_ratio + veb_ratio + f_ratio`（%） | ≤1:100；≤3:90；≤5:75；≤10:60；≤15:45；>15:30 |
| 信号质量 | 0.15 | 分析 `quality.score`，缺失时取 ECG 记录质量；`good/fair/poor` 折算 0.9/0.7/0.4 | `score×100` |

`evidenceCount` = 可用子项数。示例 factor：「静息心率约 62 bpm（近 30 天）」「HRV（RMSSD）42 ms」。

## 睡眠 sleep

- 按记录本地时区归到「夜晚日期」；忽略 `awake`、`in-bed`；只统计入睡阶段。
- 平均时长 = 有睡眠记录的夜晚总时长 / 夜晚数（不是除以固定 7 天）。
- 深睡/REM 占比 = (deep + rem) / (deep + rem + light)，需同时存在深睡/REM 与浅睡分期记录。

| 子项 | 权重 | 评分 |
|---|---|---|
| 平均睡眠 | 0.70 | 7–9h:100；6–7 或 9–10h:85；5–6 或 10–11h:65；其余 45 |
| 深睡+REM 占比 | 0.30 | 33–48%:100；28–33 或 48–53:85；23–28 或 53–58:70；18–23 或 58–65:55；其余 40 |

无分期明细时只按平均时长评分，并在 `missing` 标注。示例：「近 7 天平均睡眠 7.2 h（3 晚）」。

## 体重 weight

- 身高取成员档案 `heightCm`；体重取最近 30 天 `body-mass` 记录或手动 `weight` 指标，取较新者；否则用档案 `weightKg`。
- BMI = 体重 kg / 身高 m²；采用中国成人公开区间：

| BMI | 评分 |
|---|---|
| 18.5–23.9 | 100 |
| 24–27.9 或 17–18.4 | 75 |
| 28–29.9 | 60 |
| 30–34.9 或 15–16.9 | 45 |
| ≥35 或 <15 | 30 |

## 活动 activity

- 最近 7 天按本地日期汇总 `steps`，日均 = 有记录日期的总步数 / 天数。
- 目标 8000 步；评分 = `clamp(round(日均 / 8000 × 100), 0, 100)`。
- 示例：「近 7 天日均 8231 步（目标 8000 步）」。

## 血压 blood_pressure

取最近 30 天最新的导入 `blood-pressure` 或手动 `blood_pressure` 指标：

| 收缩压 / 舒张压 | 评分 |
|---|---|
| <90 或 <60（偏低） | 65 |
| <120 且 <80 | 100 |
| <130 且 <80 | 85 |
| <140 或 <90 | 65 |
| <160 或 <100 | 45 |
| ≥160 或 ≥100 | 30 |

## 建议 suggestions

- 无任何数据：返回 1 条「先导入健康数据或完成一次分析」。
- 有数据：优先最低分分类（<70 为 `attention`），再补充缺失项（`info`）。
- 最多 3 条；排序为 `attention` 优先，其次按优先级/分数。每条含 `id/text/category/severity/prompt`，`prompt` 供助手预置问题。
- 纯规则模板，不调用 LLM。

## API

`GET /api/v1/scores?memberId=...`（`memberId` 可省略，默认第一个成员）：

```json
{
  "overall": 78,
  "grade": "good",
  "categories": [{
    "id": "heart", "label": "心脏", "score": 86, "grade": "excellent",
    "factors": ["静息心率约 62 bpm（近 30 天）", "HRV（RMSSD）42 ms"],
    "missing": ["缺少信号质量数据"], "evidenceCount": 2
  }],
  "missing": ["睡眠", "活动"],
  "disclaimer": "基于公开区间规则的参考评分，不是医学诊断",
  "generatedAt": "2026-10-31T07:00:00Z",
  "memberId": "mem_...",
  "windowDays": 30
}
```

`GET /api/v1/suggestions?memberId=...` → `{ "items": [{ "id": "...", "text": "...", "category": "sleep", "severity": "attention", "prompt": "..." }] }`

不返回 notes、波形或文件路径。挂载由指挥官统一在 `api/__init__.py` 完成。

## 来源说明

区间参考公开的成人静息心率、HRV、睡眠时长、BMI（中国成人）、步数与血压分级建议，仅用于生活方式参考；不用于筛查、诊断或治疗决策。出现不适请就医。
