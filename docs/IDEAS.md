## Idea 001 · 日食启动动画 + 品牌标识 + 莫奈配色

**提出日期**：2026-10-28
**状态**：已记录，未实现

### 用户描述

- 打开应用时渲染一个日食景象：黑色背景、亮色光环（日冕），下方是 logo 与应用名称。
- 不用真实图片，用渲染/动画实现。
- 暗色模式：整体保持黑色，logo/光环逐渐变亮。
- 亮色模式：整体慢慢变亮，黑色圆盘逐渐变小，像日食结束，然后过渡到白色主界面。
- Logo：黑色圆盘 + 亮色光环，可据此设计正式 logo。
- 配色：莫奈风格，颜色统一、和谐、低饱和、高质量/高质感，接近 Google 系统色的感觉；主体以白色为主，最终可再决定。

### 可行性

**高**。无需真实图片，SVG + CSS 渐变/遮罩/透明度 + 轻微缩放即可完成；必要时用 Canvas 增加日冕颗粒感。Tauri 启动阶段可用 React 覆盖层，或单独的启动窗口避免白屏闪烁。

### 默认实现方案（可改）

| 项 | 默认 |
|---|---|
| 播放频率 | 每次启动 |
| 时长 | 约 1.6 秒 |
| 跳过 | 点击/按键可跳过 |
| 减少动效 | 系统开启 `prefers-reduced-motion` 时只做 300ms 淡入，不播放日食过程 |
| 暗色模式 | 背景保持近黑 `#0A0C0F`；光环从 40% 亮度升到 100%；名称淡入；主界面淡入 |
| 亮色模式 | 从黑开始；光环亮起；黑盘缩小并淡出；背景过渡到暖白 `#F7F5F1`；主界面淡入 |
| 实现位置 | 先做 React 启动覆盖层；若 Tauri 首帧有白闪，再加独立 splash 窗口 |
| 品牌名 | 下方小写字标 `eclipse health`，衬线体；可加副标题“被忽视的健康” |

### Logo 方向

- 主体：深墨圆盘 + 一圈偏暖或偏青的日冕光。
- 需要四个版本：亮色、暗色、单色、16px favicon。
- 光环颜色建议跟随主色（莫奈低饱和金/青），不要高饱和霓虹。
- 图标在小尺寸下要能识别出“圆盘 + 环”，不要依赖细节纹理。

### 与现有规范的关系

- 启动动画属于**核心品牌体验**，不是可卸载模块。
- 配色定稿后，统一替换 `docs/UI_COMPONENT_SPEC_V1.md` 中的颜色令牌；当前令牌为初稿。
- Logo 与启动动画不进入模块市场，第三方主题可换业务界面配色，但不能换启动品牌动画。
