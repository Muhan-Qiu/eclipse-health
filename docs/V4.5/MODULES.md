# 模块中心与模块工作台（V4.5）

本文描述 V4.5 中「模块中心」和「模块工作台」的界面结构，便于后续维护和扩展。

## 模块中心（`/modules`）

- **头部**：标题、说明与「安装模块」主操作。
- **更新提示**：仅当市场返回可更新模块时出现，按模块列出安装版本 → 可用版本。
- **已安装列表**（`src/features/modules/module-list.tsx`）
  - 搜索：按本地化名称、ID、简介与文案条目过滤，实时显示 `匹配数 / 总数`。
  - 信息层级：模块名 → 版本、官方/社区、运行状态、类型 → 本地化短标语 → 权限数、安装时间、模块 ID。
  - 主操作「打开」使用默认按钮；启动/停止作为次级操作；详情、启用/禁用、卸载收进「更多」菜单，卸载使用 destructive 样式。
  - 加载、空列表、搜索无结果分别使用统一的骨架/空状态。
- **审计区**：位于列表下方，支持按模块与动作筛选；模块名使用本地化文案。

## 模块工作台（`/modules/:moduleId`）

文件：`src/features/modules/workbench/module-workbench.tsx`

1. **头部**
   - 眉题「模块工作台」、模块名（`moduleDisplayName`）。
   - 名称旁的状态 chips：版本、类型、运行状态、官方自研标识。
   - 描述优先使用 `module-copy.*.json` 的本地化 `summary`/`tagline`，找不到时回退 manifest 原值。
   - 紧凑信息条：作者、许可证、安装时间、资源限制、模块 ID。
   - 操作分组：返回、刷新（图标）｜启动/停止、启用/禁用。禁用使用 outline，危险操作不抢视觉。
2. **提示区**：仅在模块禁用、崩溃或 manifest 读取失败时显示 Alert。
3. **主体**：`xl` 及以上为左右两栏。
   - 左栏：模块页面 → 仪表盘卡片 → 工具 → 模型与记录类型。
   - 右栏：权限 → 最近审计。
   - 有内容才展开为卡片；无内容使用一行虚线状态条（图标 + 标题 + 简短说明），不再占整张大卡片。
4. **模型与记录类型**：两个小块并排；任一为空时用状态条占位。
5. **权限与审计**：权限行在窄屏纵向排列，按钮不挤出容器；审计只保留时间、动作、范围（全局视图额外显示本地化模块名）。
