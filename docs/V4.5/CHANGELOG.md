# eclipse health V4.5 更新日志

> 版本号 `0.2.0`。这一版以「修 bug、补完功能、重做主题与模块体验」为主，不是新功能堆叠。
> 技术细节与复现记录见同目录 `BUGS.md`、`MODULES.md`。

## [0.2.0] 2026-11-16

### 修复

- **健康评分缺数据显示 `unknown`**：后端 `/scores` 的 `missing` 是分类显示名数组，前端却按 `{id, reason}` 对象解析，导致「缺数据：unknown、unknown…」。现在按契约显示「睡眠、体重、活动、血压」，并为缺失分类显示虚线占位卡。
- **血压分类 id 不一致**：后端 `blood_pressure` 与前端 `blood-pressure` 不匹配，导致图标和翻译取不到。现在统一为 kebab-case，并兼容旧值。
- **Windows 上带模型权重的模块无法安装**：`relay-ecg` 等包含大量 ONNX 权重时，安装器对 staging 目录做整体重命名会触发 WinError 5，表现为「模块包安装失败」。改为递归逐文件搬移并带重试，32 个模块包全部可安装；新增回归测试。
- **导入警告缺少中英文案**：补齐 23 个厂商/SCP/EDF/WFDB 警告码（`unit_inferred`、`experimental_format`、`scp_huffman`、`samsung_health_imported` 等），不再回退到后端中文长句或露出原始 code。
- **开发模式下 Geist 字体 403**：`node_modules` 是指向上一版本的目录联接时，Vite 只允许工作区内的文件。已在 `server.fs.allow` 中加入真实路径，开发预览字体正常。
- **英文界面仍出现中文评分/建议**：`/scores`、`/suggestions` 新增可选 `lang=zh|en`，评分分类、因子、缺失项、免责声明与建议文案按语言返回；前端随语言切换重新请求，不复用旧语言缓存。

### 改进 · 主题与视觉

- **8 套配色全部重做**：保留睡莲 / 日出·印象 / 日本桥的莫奈气质，重做星夜、向日葵、神奈川冲浪里、晨雾、琉璃。每套都有完整的亮/暗令牌（背景、表面、边框、阴影、图表色、状态色），不再只是换一个强调色。
- **主题空间氛围**：星夜的星点与深空、向日葵的暖光晕、冲浪里的浪层、晨雾的雾面、琉璃的青玉折光，都用低透明度 CSS 渐变实现，不增加图片资源。
- **玻璃主题更真实**：晨雾/琉璃使用半透明表面、22px 高斯模糊、1px 内高光与折射渐变；不支持 `backdrop-filter` 时自动退回不透明表面。
- **对比度**：16 个亮/暗变体的正文、次要文字、按钮文字均通过 WCAG AA 检查。

### 改进 · 布局与页面

- **侧栏**：主导航分组、当前项左侧 2px 指示条、模块中心独立滚动、设置/关于收到底部，折叠态对齐与 tooltip 保持可用。
- **顶栏**：品牌面包屑可点击，搜索与图标按钮统一高度、间距、圆角。
- **页面头部**：标题、眉题、描述、操作区统一 4/8/16px 节奏；窄屏自动纵向排列，长描述不再挤压按钮。
- **仪表盘**：空库时前置「导入 / 载入示例 / 浏览记录」快捷卡；评分卡用 5 个分类瓦片铺满（缺失项显示「数据不足」）；健康数据空状态压缩为一行；最近记录、指标概览、波形卡同排等高；1024/1280/1440 三档无横向溢出。
- **关于页 / 404**：排版与信息层级统一。

### 改进 · 模块中心与工作台

- **工作台重排**：头部改为模块名 + 版本/类型/状态/官方 chips + 作者、许可证、安装时间、资源限制信息条；主体分左右两栏，空贡献点改为单行状态提示，不再用大块空卡片占满页面。
- **模块文案本地化**：Cardia 与 Relay 模块加入中英文名称、简介、功能、用法、输入输出、限制与技术说明；中文界面不再显示 manifest 的英文 description，英文界面也不再显示中文模块名。
- **模块中心**：新增搜索、结果计数、搜索空状态；主操作「打开」更突出，详情/启停/卸载收进更多菜单；权限与审计在窄屏不溢出。
- **模块卡片**：模块贡献的仪表盘卡片标题支持按模块文案本地化；英文界面下模块返回的纯中文文案用通用占位替代，避免中英混排。
- **侧栏模块导航**：状态点、tooltip、超过上限的 `+N` 提示、当前项指示条。

### 改进 · 记录详情与波形

- **节律条重画**：高度 44→60px，双层 canvas（底层包络/质量/基线，顶层视窗遮罩）；对称 min/max 包络填充、中心虚线基线、质量差区段低饱和底色、两侧拖动手柄；拖动时只重绘顶层，不重扫整段。
- **异常搏动标注防重叠**：只标非 N 搏动，限制在可见范围，按 30px 最小间距与两行错位放置，右边缘自动翻转；选中搏动有常驻色带与上下刻度。
- **分析结果面板**：指标卡改为大数字 + 标签层级，信号质量带阈值色进度条，警告列表紧凑限高，「手表结果仅供参考」保持醒目但收敛；引擎选择与重新分析合并分组。
- **心搏列表**：行高、hover、选中态统一，筛选条与时间输入可换行不溢出。

### 新增 · 本地化与校验

- 评分/建议 `lang=zh|en` 契约与测试。
- 导入警告 23 个新文案（中英）。
- 模块安装搬移回归测试。
- 版本号统一为 `0.2.0`（应用 / Tauri / 后端 / 前端展示）。

### 说明

- 非医疗器械，不用于诊断。
- 自动更新（H5）仍需签名私钥与更新服务器，本版未启用。
- 厂商格式（Apple / Samsung / 华为 / 小米等）仍标记 `experimental`，缺少真机导出样本；解析失败请保留原始文件。
- 安装包未签名，Windows SmartScreen 会提示「未知发布者」。
