# eclipse health V4.1 更新日志

> 面向用户的行为变化。技术细节与根因见 `BUGS.md`。

## [未发布] V4.1 开发中

### 修复

- **助手回复按 Markdown 显示**：标题、加粗、列表、表格、代码块、链接不再以原始符号出现；
  流式输出保留末尾光标，站内链接可直接跳转，外链新窗口打开。
- **助手不再过度免责**：回复优先给结论和可执行建议，不再每轮追加「以上为数据解读，不构成医学诊断」；
  免责声明由界面统一展示一次。仅在涉及诊断、用药、剂量或急症症状时提示就医。
- **缺少数据时也能给建议**：说明缺哪项数据、如何补齐，并在现有信息范围内给出判断，
  不再用「我不知道 / 无法判断」代替回答。教练模式同样优先给出 1–3 个可执行步骤。

### 说明

- V4.1 基线来自 V4 `v4` 分支（commit `42377bc`）。
- 红旗症状（胸痛、晕厥、呼吸困难等）仍会立即建议停止活动并就医，此安全行为未改变。
