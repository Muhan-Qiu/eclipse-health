# eclipse health V4.3 更新日志

> 面向用户的行为变化。技术细节见 `MODULE_WORKBENCH.md`。

## [0.1.3] 2026-11-08

### 新增

- **每个模块都有自己的工作台**：安装后在侧栏点击模块，或从模块中心点「打开」，即可进入 `/modules/:moduleId`。工作台集中展示模块状态、版本、作者、许可证、资源限制、声明式页面、仪表盘卡片、工具试运行、模型卡、记录类型、权限与最近审计。
- **没有声明页面的模块也能用**：Cardia、relay 等分析模型，以及数据导入/工具类模块，都有工作台；没有 `ui.pages` 时显示状态、模型卡、工具、权限和审计，不再只能停留在模块列表。
- **助手「+」选择模块**：对话输入区新增「+」，可勾选本轮优先使用的模块。所选模块以 chips 显示，随消息发送 `moduleIds`；切换会话会恢复上次选择，用户消息和透明面板都会回显本轮模块。
- **Agent 优先所选模块**：所选模块的工具排在工具目录前面，并在系统提示词中列出模块名称、工具与页面；其他已安装且启用的模块工具仍然可用，不是白名单。
- **模块校验脚本**：新增 `npm run check:modules`（`module.json` 结构/编码 + 全仓编码扫描）和 `npm run check:packages`（`.ehmod` ZIP、`module.json`、`checksums.json` sha256）。

### 改进

- 模块中心每个模块增加「打开」主按钮；模块详情面板增加「打开工作台」。
- 声明式页面的「返回模块」现在回到该模块工作台，而不是模块列表。
- 版本号统一为 `0.1.3`（应用 / Tauri / 后端 / 前端展示）。

### 说明

- 模块选择只影响工具排序与提示词，不改变权限，也不会自动读取模块数据。
- 工作台只渲染模块声明的 JSON，不执行模块提供的任意前端代码。
- 非医疗器械，不用于诊断。
