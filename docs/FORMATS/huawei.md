# 华为运动健康 心电图（ECG）格式要点

来源：Huawei Health Kit <https://developer.huawei.com/consumer/en/hms/huawei-healthkit/>
（HMS Core 健康数据开放能力总览）；华为运动健康 App 的 ECG 功能说明只描述「心电分析」结果页。

**结论：未找到公开的 ECG 原始波形导出格式，也没有公开样本。需要用户提供。**

## 已知事实（有来源）

- 华为手表（Watch GT / Watch D 等）与「华为运动健康」/「华为心电分析」配合采集单导联 ECG，
  App 内可查看波形并分享 **PDF/图片报告**。
- Huawei Health Kit 向第三方开放的是健康数据（步数、心率、睡眠、运动等）读取能力；
  公开文档没有 ECG 原始波形的导出/读取接口——按现有资料推断为不开放（依据：Health Kit 数据类型列表
  与公开 API 文档中没有 ECG 波形条目）。
- 因此没有可复现的字段规范：列名、单位、采样率、时间格式都**未知**，禁止猜测。

## 适配器需要的字段（用户提供样本后确认）

| 项 | 说明 |
|---|---|
| 文件容器 | CSV / JSON / ZIP / 其他；若只有 PDF，当前任务不做 PDF 导入 |
| 时间列 | 绝对时间（时区）还是相对秒；字符串格式 |
| 电压列 | 单位 V / mV / µV / 整数 ADC；增益、基线 |
| 采样率 | 字段名或时间步长 |
| 导联 | 单导联（Lead I）时字段怎么写 |
| 元数据 | 设备型号、采集时间、心率/诊断结论 |

## 已知坑

- 华为不同型号/App 版本的导出差异大，不能把某一个样本的列名当规范。
- 分享出来的 PDF 是渲染图，不是数据；本批明确不做 PDF 导入。
- 若用户给的是 App 内「数据导出」的压缩包，先列目录再解析，不要假设固定文件名。
- 时间若是本地时间字符串，必须知道设备时区，否则记录时间会偏移；适配器应允许用户校正时区。
