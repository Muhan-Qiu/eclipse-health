# 用户反馈记录（eclipse health）

> 用途：你随时把意见写在这里或直接发在对话里；指挥官按轮次分配、逐条回复处理结果。
> 不需要等「封装完成」再提；预览包/开发模式都能边用边提。

## 怎么提最省事

每条按下面格式写，一行也行：

```
页面：仪表盘 / 记录详情 / 设置 / 助手 / 模块 …
操作：我点了什么、做了什么
期望：我希望它怎样
实际：现在怎样（有报错就贴）
优先级：必须改 / 想改 / 以后再说
截图/录屏：（可选，放 reports/screenshots/ 或直接贴）
```

动画/视觉类额外写：**哪个动作**（启动、切页、卡片入场、波形交互、悬停/点击反馈）、**太快/太慢/太花/太素**、**亮色还是暗色**。
