# eclipse health V4.2 更新日志

> 面向用户的行为变化。技术细节与根因见 `BUGS.md`。

## [0.1.2] 2026-11-07

### 修复

- **其他分析引擎可以正常分析心电图**：此前除 Cardia 外，relay-ecg 的 7 个模型（relay-k2 / k4 / k8 / k12、BiLSTM、T-LSTM、1D-ResNet）在导入的 ECG 上都会报「输入维度不匹配」或 `cannot reshape ...`。现在通用 ONNX 执行器会按模型声明执行 R 峰切窗、双导联输入、逐导联归一化和 64 搏序列，7 个模型均可完成分析。
- **单导联记录自动适配双导联模型**：手环/手表导出的单导联 ECG 会自动复制为模型要求的双导联，并在结果中提示。
- **采样率自动重采样**：500 Hz / 250 Hz 等记录会重采样到模型训练使用的 360 Hz。
- **错误信息可读**：形状、心搏数量、R 峰检测等失败现在显示中文业务错误（如「序列模型需要至少 64 个连续心搏」），不再直接暴露 Python `ValueError`。
- **睡眠模型不再误选**：relay-sleep 的睡眠分期模型需要 EEG/特征输入，不再出现在心电记录的可选分析引擎中，并会说明不可用原因。

### 说明

- V4.2 基线来自 V4.1 分支（commit `63b44d9`）。
- 本版只修上述一个问题，Cardia 分析路径、导入、记录、报告、助手等行为未改动。
- 分类结果仍是模型级参考，非逐搏诊断，不能替代医生判断。
