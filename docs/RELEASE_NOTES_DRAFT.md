# eclipse health 0.1.0 · 发布说明（草稿）

> 状态：草稿。安装包由发布轮统一构建，文件大小与 SHA-256 在打包后填入文末表格。

## 这次带来什么

- **ECG 导入**：WFDB、CSV、EDF、SCP-ECG；拖拽/选择文件、格式自动探测、导入前预览。
- **健康数据导入**：Apple 健康导出（`export.xml/zip` + ECG CSV）、小米运动 CSV，导入步数/心率/睡眠/体重/血压；健康数据页可筛选、翻页、查看来源与原始 payload。
- **AI 数据导入**：识别不了的文件可交给本地 Agent 在无网沙箱中写脚本解析，先给出候选记录与证据，确认后才写入；覆盖 CSV/HTML/PDF/XLSX/ZIP 等，内置 10 家厂商导出教程。工具调用与代码全程可见。导入弹窗现在把「用 AI 解析文件」放在首位；Agent 预算提升到 24 次工具调用 / 300 秒。
- **Samsung Health 原生导入**：直接选择 `samsunghealth_*` 导出的文件夹或 ZIP，自动解析步数（按天汇总）、心率、压力、睡眠、运动、体重、呼吸率；真实导出实测 360 条记录，无需 AI。
- **35 个模型服务商预设**：OpenAI、Anthropic、Gemini、DeepSeek、Kimi、智谱、通义、火山方舟、OpenRouter、Ollama、CC Switch 代理等；只需选服务商 + 填 Key，旧配置无需迁移。
- **自定义仪表盘卡片**：用已导入的压力、血氧、血压、运动等数据创建 stat/趋势卡片；助手只生成草稿，用户确认后才保存。
- **分析**：内置 Cardia 2.0 模型，输出信号质量、R 峰/心搏与心率/间期测量；引擎列表按后端注册表展示，可切换引擎重新分析；第三方 analysis-model 模块可注册自带 ONNX 引擎。
- **记录**：记录库、详情（波形与导联、分析结果）、按时间/设备/标签筛选、收藏、软删除；示例记录一键载入。
- **趋势与对比**：指标随时间变化，记录之间并排对比。
- **报告**：生成 PDF / PNG 报告并保存到本地。
- **助手**：可选 OpenAI、Anthropic、本地 Ollama 或兼容代理；工具调用过程可见；API Key 用 Windows DPAPI 加密，只发送摘要与测量，不发送波形、备注或姓名。安装的 `ai-tool` 模块可自动出现在工具表中。
- **模块**：安装/卸载 `.ehmod`，查看权限与审计；模块可提供首页卡片、声明式页面、助手工具；官方 Cardia 分析模块随包预装。
- **数据管理**：ZIP / JSON / CSV 备份与恢复、隐私清理、诊断日志导出。
- **概览与评分**：首页「概览」显示健康评分（心脏/睡眠/体重/活动/血压，缺项不显示）、规则建议、健康数据摘要；可拖拽/调整宽度/隐藏卡片并导入导出布局。
- **教练与记忆**：Coach 模式（睡眠/心脏/运动/压力/体重预设）、Open-Meteo 天气、可编辑的个人记忆（可关闭注入）。
- **主题与动效**：8 套主题（莫奈三套 + 3 高饱和 + 2 玻璃）、启动日食、涟漪 logo、淡入淡出导航、30 句每日中英健康名言。
- **对外 API**：设置页创建/撤销 API Key；REST、OpenAI 兼容端点、stdio MCP；仅本机，key 只显示一次、存 hash。
- **30 个可选模块**：官方索引 10 个（第一方 + 已验证第三方）、社区索引 22 个；按需安装（`dist/modules/*.ehmod` + 签名索引），覆盖 ECG/HRV、睡眠/活动、营养/代谢、心理/习惯、导入/导出、UI 卡片；依赖装在模块独立 venv / deps 目录，安装后可在后台继续使用应用。
- **模块市场**：应用内「官方市场 / 社区市场 / 本地文件」三种安装入口；索引 Ed25519 签名、包 sha256 校验；社区模块标注未审核。静态市场站/开发者提交模板见 `marketplace/site/` 与 `.github/`。
- **动效**：启动日食、侧栏 logo 循环、导航斜向转场、卡片/列表入场、数字滚动、波形选中反馈；遵循系统「减少动画」。
- **布局校正**：1024/1280/1440 下同排卡片等高、无横向溢出；助手、报告、记录详情双栏底边对齐；编辑模式与浏览模式卡片宽度一致。

## 安装

1. 系统要求：Windows 10/11 x64。
2. 运行 NSIS 安装包，启动 `eclipse health`；后端 sidecar 会自动在本机 `127.0.0.1:8765` 启动，无需单独安装 Python。
3. 安装包未签名，SmartScreen 可能提示「未知发布者」：选择「更多信息 → 仍要运行」。

数据保存在 `%LOCALAPPDATA%\eclipse-health`，卸载时不会删除；需要彻底清除请先备份再手动删除该目录。

## 已知限制

- **自动更新未启用**：当前版本不检查也不下载更新，需要手动安装新版本；启用前需要签名私钥与更新服务器。
- **部分厂商健康数据尚未实现**：Samsung Health 已用真实导出验证；Apple / 小米用合成夹具验证，真实导出可能有字段差异；华为 / Zepp / OPPO 等仍待脱敏样本。
- **仅 Windows**：桌面端目前只构建 Windows 版本。
- **仅有 Cardia 一个内置分析引擎**：第三方引擎需以模块形式安装；ONNX loader 已就绪，真实第三方 ECG 模型待作者提供。
- **未签名**：首次运行可能触发 SmartScreen 提示。
